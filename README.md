### ⚖️ Smart Legal Risk Analyzer — Contract Risk Classification Engine

> **Predicts contract litigation risk (Low/Medium/High) and suggests safer clause rewrites.**

[![GitHub](https://img.shields.io/badge/View_on_GitHub-181717?style=flat-square&logo=github)](https://github.com/Satyam999999/LegalMind-Intelligent-Risk-Analyzer)

**Analysis highlights:**
- ⚖️ **Risk classification model** — hybrid Legal-BERT + LightGBM trained on the CUAD dataset, with class weighting to correct for imbalance between risk levels
- 📄 **Real-time clause segmentation** — parses unstructured PDF contracts into individually analyzable clauses
- ✍️ **Actionable output, not just a score** — Gemini API generates suggested clause rewrites for flagged risky sections
- 🔍 **Explainability-first** — feature importance interpretation so every high-risk flag is defensible, not a black-box label

```
Stack: Python · Legal-BERT · LightGBM · Pandas · Scikit-learn · Gemini API · NLP · Flask · Streamlit
```

### 🎮 GameMetrics — Mobile Game User Analytics & Retention Insights

> **End-to-end product analytics workflow: retention, monetization, churn, and a statistically validated A/B test.**

[![GitHub](https://img.shields.io/badge/View_on_GitHub-181717?style=flat-square&logo=github)](https://github.com/Satyam999999/-GameMetrics-Mobile-Game-User-Analytics-Retention-Insights)

**Analysis highlights:**
- 📈 **Retention & engagement** — DAU/MAU, stickiness (10.9%), and cohort-based D1/D7/D30 retention curves; found 43.8% D7 retention, 2x the casual-game benchmark
- 💰 **Monetization segmentation** — identified the top 5% of paying users ("whales") driving 35% of total revenue, with Battle Pass as the top-grossing SKU
- 🔮 **Churn prediction** — logistic regression on early-behavior features; honestly reported a near-random AUC (0.518) as a signal to extend the feature window rather than overfit
- 🧪 **Statistically validated A/B test** — two-proportion z-test confirming a 22% relative D7 retention lift (p < 0.0001) with a full go-live recommendation

```
Stack: Python · Pandas · Scikit-learn · SciPy · Statsmodels · Matplotlib · Seaborn · Jupyter
```
